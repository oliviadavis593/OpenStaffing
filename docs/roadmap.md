# Roadmap

Built around the Illinois legislative calendar: Phase 1 lands before the new General Assembly
starts in January 2027, when district fact sheets matter most.

| Window                     | Focus                                                                                       | Done when                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Oct to Nov 2026            | Foundation, Report Card ingest, national CMS ownership ingest, crosswalk, hospital profiles | Every Illinois hospital has a profile with staffing and owners |
| Dec 2026 to early Jan 2027 | Compare, rankings, map, system view, methodology, CSV downloads, private partner preview    | Partner feedback folded in                                     |
| Mid-January 2027           | Public launch                                                                               | Live site, launch post, Chi Hack Night talk                    |
| Feb to Apr 2027            | District lookup, fact sheet PDFs, ownership alerts, public API                              | Fact sheets used in a legislator meeting                       |
| May to Aug 2027            | Multi-state: adapter interface, national ownership tracker, second state with a partner     | National ownership tracker live                                |
| Partner request only       | Union-controlled tools (unsafe assignment log, staffing plan tracker)                       | Written data agreement                                         |

## Epics

Foundation · StaffingPipeline · OwnershipPipeline · HospitalProfiles · TrustAndMethodology ·
OpenData · AdvocacyToolkit · MultiState · PartnerTools · OutreachAndAdoption

## Not building

A gig-shift marketplace, anything that stores patient information, single-score hospital
"grades," and anything that requires a hospital login.
