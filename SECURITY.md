# Security Policy

OpenStaffing publishes public data only, but we take the security of the site, its
infrastructure, and anyone who uses it seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Instead, use GitHub's
[private vulnerability reporting](../../security/advisories/new). Include steps to reproduce and
the impact you expect.

You can expect an acknowledgment within 7 days. We will keep you updated and credit you in the
fix unless you prefer otherwise.

## Scope

- The public site and its API
- The ingest pipeline and GitHub Actions workflows
- Any partner tool built in this repository

## Data concerns

If you believe OpenStaffing is showing personal information (for example, anything identifying a
patient or an individual nurse), report it the same way. It will be taken down first and
investigated second.
